## 1. Definitions used (from the C source, not from the notes)

- Representation: anchor y = 2^a 3^b 7^c, shift nu, digits (d_j, e_j) with V = R_nu + sum (d_j - 1) 10^(e_j) = y + w R_96 (w = wrap, R_L = (10^L - 1)/9).
- Depth-1 word: set F of digits placed at copy 0 (positions e_j in [0, 96)); at most one digit per residue e; the shipped `dc_stage` keeps F iff the 96-window coset meets the anchor coset.
- Level-480 child: for every digit a residue s in {0..4} (position e + 96 s mod 480) and for nu a shift; value `V_child = V + (10^96 - 1) * Delta`. `run_rep480` lists the children with `Delta == tau (mod PT)`, tau = -w/9 (mod PT), by a meet-in-the-middle over unit compositions (`mitm480`); pairs each child with the words whose fixed digits all sit at residue 0 (`comp`); cuts the word coset by the 21 + 1 level-480 primes (`chain480`); then applies the 480 window.
- Shadow: the child with every digit at residue 0, nu unchanged (Delta = 0). It is a member of the solution set iff tau = 0, i.e. iff w = 0.

## 2. Theory: the depth-D survival condition (derived on paper)

Fix a wrap-0 representation (V = y) and a depth-1 word F. Let Lambda_L = Lambda_96 intersected with the kernels {3^b 7^c == 1 (mod p)} over the level-L primes in use, and X_F = R_L + sum_F (d_j - 1) 10^(e_j).

1. Window side is depth-independent. A digit at copy t >= 1 contributes 10^(e + 96 t), which is 0 modulo 2^(a+c) 5^(c5) once a + c < 96 and c5 <= 5. So the 2,5-adic class of the window is X_F, whatever the depth; "depth 2 never kills" (DEEPCUT) is this statement. Used range: a + c <= 58 in all data (the code asserts it).
2. The shadow's modular coset is the anchor coset. V_child = V = y, so (b_y, c_y) satisfies every modular condition of every level (the witness lemma, HSHADOW 8). The shadow survives level L iff there is lambda in Lambda_L with `y * 3^(lambda_b) 7^(lambda_c) == X_F (mod 10^L)`, i.e. iff `X_F / y` lies in the image of Lambda_L in U(2^(L-a)) x U(5^L).
3. That image is a product H_2 x H_5. Z^2 is dense in Z_2^2 x Z_5^2 (CRT), so the integer span of two generators has the product of the two local images. Each factor is generated by two elements: H_5 is cyclic (the subgroup of order lcm of the generator orders), and H_2 sits in Z/2 x Z/2^(L-a-2) and contains 1 + 2^c2 Z for the least c2 with `(0, 2^(c2-2)) in H_2`. So membership depends only on `X_F mod 2^(a+c2)` and `X_F mod 5^t5`.
4. Computed exponents (`cc_lib.py Window`, exact big-integer images of the lattice basis; `levels_tab.out`): Lambda_96: c2 = 9, t5 = 5, finite parts trivial. 96+192: 9, 5. 96+192+384: 13, 5. 96+480 (the lattice `chain480` uses): c2 = 10, t5 = 5, finite parts trivial. These reproduce the 2-adic jumps of the G_L table in HSHADOW 8 (G_192 same as G_96, G_384 the 2-adic killer, G_480 one bit more). The Lambda_96 row reproduces Theorem F, including content(Lambda_96) = 13545045360000 and index 280999509749509611991995562563818636457519792000000000000 (equal to the C binary's).
5. With trivial finite parts, `9 (X_F - y) == -(10^nu + 9 S_U + w) (mod 10^L)` turns the condition into **`10^nu + 9 S_U + w == 0 (mod 2^(a+c2) * 5^t5)`**, S_U = sum over digits not in F. Depth 1: c2 = 9 (Theorem F). Level 480 shadow: c2 = 10. The side conditions `v2(X_F) = a`, `5 does not divide X_F` are implied.

What is derived: items 1 to 3 and 5 (ordinary arithmetic; item 3 uses the standard fact that a finitely generated subgroup of Z_2 or Z_5 is determined by the minimal valuation of its generators); item 4 is computed. What is observed only: that the images computed from the 21 + 1 level-480 primes the build carries equal the images of the full level (the unfactored cofactors of Phi_d(10) are omitted by the build, which is a valid weaker level, and my numbers describe that weaker level). Not derived: any statement about the non-shadow children.

Non-shadow children: `Delta == tau (mod PT)` with PT = 1.27e17 from the seven primes at which the word lattice has trivial image (printed for s000, t121, t348 by `pt.py`; identical). Each such child is an accident at rate space/PT; the unrestricted space reaches 1.6e19 (expected 100 solutions), the word-restricted spaces are 1e10 to 1e14 (expected 1e-7 to 1e-3). No closed form exists for the solution set; I found none and the data show they are real: 10 alive non-shadow points in the 1,335 set (Section 4).

## 3. The lever that holds: word-restricted MITM (built as a copy)

A child is used only if it is compatible with some word (residue-0 count >= the word's fixed count, unit by unit). So the solution set needed is the union over words of {children with n0_u >= f_u for all units u, Sum == tau}; a word whose fixed vector dominates another word's is redundant. `src/cport_cong.c` (copy of `tierc-r2shadow/src/cport_r2.c`, md5 d335e210e9eb2fee065ebbb2d78d43ec) adds:
- `--word-mitm`: collect the inclusion-minimal fixed vectors over the words that pass `wok`, run `mitm480` once per minimal vector on the unit set restricted to compositions with n0_u >= f_u, map the composition indices back, sort and deduplicate. Everything downstream (`comp`, `chain480`, window, nearest point) is unchanged.
- `--dump-reps FILE`: one line per representation with the recorded counters.
- `src/cport_cong_mut.c`: the planted negative, which demands n0_u >= f_u + 1 whenever a unit has a free copy.

Work estimate before building (`wordspace.py`, mimicking the split in `mitm480`): median 387x fewer table operations, total 3.9e12 -> 1.4e9 over the 550. The build confirms it.

2. Agreement on recorded cases does not exercise wrap >= 1 shadows (there are none) and exercises wrap-1 accidents only through the C build's own counters.

5. The two k = 31 verdicts and the k = 30, 31 rows of the U'' table inherit R2BILL's seam (interval-certified integer N, second-typing and planted-negative checks not repeated for rows k = 30 to 34).
6. The bill uses the old samples of survivors; costs are process-per-survivor on one machine (user + sys).

## 11. Do not retry without new data

- A shadow-only congruence verdict as a replacement for the certificate: wrap >= 1 representations carry alive non-shadow points (10 in the 1,335 set, one case's verdict category). Needs a bound that excludes them, not a search that ignores them.
- A per-anchor or per-(a, depth) cache of the subset-sum: 549 of 550 instance keys are unique.
- Pushing the depth beyond 480 for the shadow with a +1 bit: the 96+192+384 lattice already has c2 = 13 and the 480-only lattice 10; mixing needs the chain of the intersected lattice (computed in `levels_tab.out`), not an extrapolation.
- Estimating the Tier B certificate bill from this lane: no Tier B survivor was run.
