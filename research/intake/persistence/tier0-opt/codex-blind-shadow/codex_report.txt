**1 → Child correspondence and the exact difference formula.**

Write
\[
R_n=\frac{10^n-1}{9},\qquad
w_j=(d_j-1)10^{e_j},
\]
where \(0\le e_j<96\) and \(0\le\nu<96\).

A depth-1 word partitions the labeled special digits into:

- \(F\): fixed at actual position \(e_j\), meaning copy \(t_j=0\).
- \(U\): unplaced, meaning actual position \(e_j+96t_j\), with \(t_j\ge1\).

Its actual length satisfies \(n=\nu+96q\). At level 192, the additional information is
\[
S=\{j\in U:t_j\equiv1\pmod2\},
\qquad sn=q\bmod2\in\{0,1\}.
\]

Thus the formal level-192 representative is
\[
V_{S,sn}
=
R_{\nu+96sn}
+\sum_{j\notin S}w_j
+10^{96}\sum_{j\in S}w_j.
\]

The **representative shift is 96**, not 192. An odd unplaced copy has \(t=1,3,5,\ldots\); an even unplaced copy has \(t=2,4,6,\ldots\). In particular, an even copy is represented by residue \(e_j\), although its actual position is at least \(e_j+192\).

Let
\[
V=R_\nu+\sum_jw_j.
\]
Because \(sn\) is binary,
\[
R_{\nu+96sn}-R_\nu
=sn\,10^\nu\frac{10^{96}-1}{9}.
\]
Consequently,
\[
\boxed{
V_{S,sn}-V
=
(10^{96}-1)
\left(\sum_{j\in S}w_j+sn\,\frac{10^\nu}{9}\right).
}
\]

The entirely integral version is
\[
\boxed{
V_{S,sn}-V
=
\frac{10^{96}-1}{9}
\left(9\sum_{j\in S}w_j+sn\,10^\nu\right).
}
\]

Here \(\nu\) is **the original length residue modulo 96**, not the actual length and not the number of special digits.

When \(sn=1\), the quantity called \(\Delta\) is generally rational, not an integer. Modulo a modulus coprime to 9, its precise meaning is
\[
\Delta_M(S,sn)
=
\sum_{j\in S}w_j+sn\,10^\nu\,9^{-1}\pmod M.
\]

For any prime \(p\ne3\) dividing \(10^L-1\), reducing the length modulo \(L\) is legitimate because
\[
R_{r+Lq}-R_r
=
10^r\frac{10^{Lq}-1}{9}
\equiv0\pmod p.
\]
It is **not** generally legitimate modulo the whole integer \(10^L-1\), where division by 9 is unavailable.

This correspondence is between **labeled formal residue choices**. Repeated identical digit/residue pairs can give the same multiset child. Actual-position collisions, placement inside the number, and window compatibility impose additional restrictions.

**2 → The congruence criterion needs a shadow-residue hypothesis.**

Let a word’s exponent coset be
\[
C_W=o_W+\Lambda_W\subseteq\mathbb Z^2,
\]
and define
\[
\chi_p(b,c)=3^b7^c\pmod p.
\]

The lattice’s image is trivial precisely when
\[
\chi_p(u)=1
\]
for every basis vector \(u\) of \(\Lambda_W\). Then every point of the coset has the same S-unit residue
\[
T_{W,p}=2^a\chi_p(o_W).
\]

To obtain HSHADOW’s zero-target criterion, one must additionally establish
\[
\boxed{T_{W,p}\equiv V\pmod p.}
\]

Under these two hypotheses,
\[
V_{S,sn}\equiv T_{W,p}\pmod p
\iff
(10^{96}-1)\Delta_p(S,sn)\equiv0\pmod p.
\]

My independent arithmetic checks give
\[
10^{96}\equiv-1\pmod{193},\qquad
10^{96}\equiv-1\pmod{769}.
\]
Thus \(10^{96}-1\equiv-2\) is invertible at both primes.

Trial division confirms that 193 and 769 are prime, and
\[
\boxed{193\cdot769=148417.}
\]
Their multiplicative orders of 10 are both 192. CRT therefore gives
\[
\boxed{
\text{passes both prime cuts}
\iff
\Delta_{148417}(S,sn)=0,
}
\]
**provided the shadow-residue hypothesis holds at both primes**.

Without it, the correct condition has a word-dependent target:
\[
\Delta(S,sn)\equiv
(T_{W,p}-V)(10^{96}-1)^{-1}\pmod p.
\]

The anchor’s existence alone does not establish the missing hypothesis: a word’s 10-adic cut need not retain the anchor point, and an anchored representation can have \(V=y+\kappa R_{96}\), rather than \(V=y\).

For the content argument, define
\[
c=\gcd\{|u_{i,j}|:\text{all coordinates of a lattice basis}\}.
\]
The required interpretation is
\[
2^9\,3^2\mid c,
\]
so every coordinate of every lattice vector is divisible by \(4608\). Since
\[
193-1=192\mid4608,\qquad769-1=768\mid4608,
\]
Fermat’s theorem implies trivial images.

Divisibility by **768 already suffices**. “The content contains 4608” is potentially misleading ideal language: the needed assertion is that the content integer is **divisible by** 4608.

**3 → Level 384 introduces another set of binary choices.**

After the level-192 shadow, every unplaced digit has even copy index:

        throw Error(`shadow offset mismatch at ${p}`);
    }
    const rivals = [];
    for (const {mask, sn} of dp.candidates()) {
      if (mask & fixed) continue;
      const value = V + (10n ** L - 1n) * sum(mask) +
        Z(sn) * 10n ** nu * rep(L);
      if (primeCuts(C, value, a, ps192))
        rivals.push({S: ids(mask), sn});
    }
    if (rivals.length)
      return {
        id: input.id, verdict: "NOT_ESTABLISHED",
        reason: "nonshadow candidate passes all level-192 prime cuts",
        word: word.id, rivals, dp_nonshadow_count: dp.count
      };

    C192 = windowCut(C192,
      rep(192n) + sum(fixed), 192n, a);
    if (!C192) {
      words.push({
        id: word.id, branches: [],
        diagnostic_fixed_V: "dead_by_192"
      });
      continue;
    }
    const diagnostic = primeCuts(C192, V, a, ps384);
    const diagnosticWindows = [];
    if (diagnostic)
      for (const A of submasks(free)) {
        if (new Set(ids(A).map(j => digits[j].e)).size !== ids(A).length)
          continue;
        const Cw = windowCut(diagnostic,
          rep(384n) + sum(fixed) + 10n ** 192n * sum(A),
          384n, a);
        if (Cw)
          diagnosticWindows.push({
            fixed_at_copy2: ids(A), ...analyze(Cw, U)
          });
      }
    const branches = [];
    for (const T of submasks(free)) {
      for (let sn = 0; sn <= 1; sn++) {
        const value = V + (10n ** 192n - 1n) * sum(T) +
          Z(sn) * 10n ** nu * rep(192n);
        const child = primeCuts(C192, value, a, ps384);
        if (!child) continue;
        for (const A of submasks(T)) {
          if (new Set(ids(A).map(j => digits[j].e)).size !== ids(A).length)
            continue;
          const Cw = windowCut(child,
            rep(384n) + sum(fixed) + 10n ** 192n * sum(A),
            384n, a);
          if (Cw)
            branches.push({
              shifted_to_copy2: ids(T), sn,
              fixed_at_copy2: ids(A), ...analyze(Cw, U)
            });
        }
      }
    }
    words.push({
      id: word.id,
      diagnostic_fixed_V: {
        prime_cut_survives: !!diagnostic,
        windows: diagnosticWindows
      },
      branches
    });
  }
  const branches = words.flatMap(w => w.branches);
  return {
    id: input.id, dp_nonshadow_count: dp.count,
    verdict: !branches.length ? "CLOSED_CUT" :
      branches.every(x => x.above_upper_bound === true) ?
        "CLOSED_SANDWICH" : "OPEN",
    words
  };
}

Backtracking targets \(0\) for \(sn=0\), and \(-10^\nu9^{-1}\) for \(sn=1\). It excludes \((\varnothing,0)\).

**5 → Discrepancies and ambiguities found.**

**→ Rational versus integer \(\Delta\).** [HSHADOW §2.2](/Users/jwross/Documents/cairn/research/intake/persistence/tier0/HSHADOW.md:28) does not specify that \(10^\nu/9\) means modular inversion. Its displayed difference equality is valid over the rationals; the integral form above removes the ambiguity.

**→ Representative versus actual value.** “The same number” refers to the pattern representative \(V\). Unplaced digits can have actual positions hundreds of places higher. Confusing those two values would invalidate the correspondence.

**→ Trivial image does not determine the coset residue.** The passage from trivial lattice image to the zero-target DP needs the additional check \(2^a\chi_p(o_W)=V\). The implementation checks it directly and refuses otherwise.

**→ The content statement is scoped to \(a=0\).** [§2.1](/Users/jwross/Documents/cairn/research/intake/persistence/tier0/HSHADOW.md:19) gives the stronger content computation for \(a=0\); that does not establish it for every \(a\). The residual in §5 acknowledges the general divisibility lemma is open. Direct basis-image checks avoid assuming it.

**→ “Exactly one shadow” needs an existence check.** Eliminating every nonshadow candidate proves **at most one** surviving child. The shadow must itself pass the remaining five primes and the \(K=192\) window before “exactly one” follows.

**→ The \(K=192\) window refinement must be explicit.** “The shadow’s level-192 coset” in [§3.3](/Users/jwross/Documents/cairn/research/intake/persistence/tier0/HSHADOW.md:51) leaves unclear whether this refinement is included. **→ The level-384 lift choices are missing from the argument.** Both \(T\) and \(sn_2\) affect all four new prime residues. No argument in the permitted documents establishes that testing unchanged \(V\) covers them.

**→ Unchanged \(V\) and arbitrary copy-2 placements describe different branches.** The literal unchanged representative is \(T=\varnothing,\ sn_2=0\), whose unplaced digits cannot occur at copy 2. **→ Child counts depend on labeling and on the window stage.** Repeated digit/residue pairs reduce distinct multiset children. Moreover, a prime-stage child with odd copies can split into several window words, according to which digits are fixed at copy 1.
