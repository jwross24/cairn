## asupersync v0.4.9 (@ 9eb0600e6ef4)

**What it actually is.** A structured-concurrency async runtime for Rust (regions, obligations, explicit `Cx` capability context) with an unusually large deterministic "lab" test harness, a trace/replay stack, an in-house RaptorQ codec for its ATP transfer protocol, and a Lean/TLA+ "formal posture" lane. 4,399 `.rs` files, `tests/` has 1,460 entries, nightly-pinned (`rust-toolchain.toml`: nightly-2026-07-05), `#![deny(unsafe_code)]` with allowlisted modules (`src/lib.rs:54`). Last commit 2026-08-20. License is MIT **with an OpenAI/Anthropic rider** (`LICENSE:1-40`) — see Gotchas.

**README vs code**

- "DPOR" (SOURCE-MAP, README) → overstated. `DporExplorer` detects races (`src/trace/dpor.rs:352,430`) but "backtracks" by hashing `(seed, race location)` into a *new seed* and re-running; it never forces the alternate interleaving (`src/lab/explorer.rs:812-829`; the module doc itself says true DPOR is a "future phase", `:17-19`). Race-guided seed sweep, not DPOR.
- "Spectral early warnings … conformal bounds and anytime-valid evidence" → all three exist as code (`src/observability/spectral_health.rs:1-60`; `src/lab/conformal.rs:534-560`; `src/lab/oracle/eprocess.rs:224-255`).
- "Drain progress certificates (Azuma/Freedman)" → code exists (`src/cancel/progress_certificate.rs:1-90`) but its own doc says one trace "does not itself prove bounded-time termination" and the Freedman branch is "retained for auditability, not presented as stronger evidence" (`:11-37`). Diagnostics, not a guarantee.
- "Budgets" → `Budget{deadline,poll_quota,cost_quota,priority}` with meet = componentwise min / priority max (`src/types/budget.rs:173-182`, `combine_untraced`). Poll quota is decremented per poll **only in the lab runtime** (`src/lab/runtime.rs:3851-3859`); production `StoredTask::poll` only traces `polls_remaining` (`src/runtime/stored_task.rs:93-107`) and exhaustion is detected cooperatively at `Cx::checkpoint` (`src/cx/cx.rs:2240-2280,2603-2648`). README's hedged wording ("sufficient conditions only where a bound is published") matches.

### M1. ForcedSchedule exact-replay receipt + ScheduleCertificate
- **Mechanism.** Each lab dispatch is hashed into a running 64-bit `ScheduleCertificate` over `(task index+generation, lane∈{Cancel,Timed,Ready,Stolen}, step)` (`src/runtime/scheduler/priority.rs:1276-1281,1325-1337`). Optional recorder captures `(task_gen, worker, lane, at_step, at_nanos)` per dispatch; `finish` binds seed, config hash (domain-separated, `src/lab/runtime.rs:1115-1128`), terminal steps/nanos/hash/quiescence (`:2236-2284`). `run_forced_schedule` replays by *removing the exact recorded task from its exact queue* before polling — no RNG fallback — and returns typed errors `EarlyRunnable / StepMismatch / TimeMismatch / ScheduleExhausted / TerminalMismatch / CertificateMismatch` (`:2303-2385`, `:3740-3790`). Serialized artifact is sealed with a domain-separated SHA-256 (`:1204-1209`). A deletion-only "candidate" mode supports delta-debugging without letting the caller synthesize dispatches (`:181-260`).
- **Home.** Reproducibility gate ("no substrate node = inadmissible") and substrate certificates; skill self-tests for any Cairn component that is itself concurrent (orchestrator, workers).
- **Cost.** Presupposes you own the scheduler; the receipt format is ~100 lines to re-implement; zero deps beyond a hash.
- **Evidence.** PROVEN-in-source: `src/lab/runtime.rs:9684-9718` records 6 dispatches, replays on a fresh runtime, asserts identical observations and hash; `:6841-6876` two same-seed runs equal on fingerprint/certificate/oracle JSON; `tests/lab_determinism.rs:149-183`; `src/lab/deterministic_validation_tests.rs:167-204`.
- **Epistemics risk.** None; strictly strengthens "replayable or inadmissible".

### M2. Seeded-lab determinism recipe (what to record)
- **Mechanism.** One seed → xorshift64 scheduler RNG, separate `entropy_seed`, virtual clock from `Time::ZERO`, seeded hasher for every set/map on the hot path, one `rng.next_u64()` per step recorded to the trace (`src/lab/runtime.rs:2066-2135,3710-3720`; `src/lab/config.rs:123-179`). `TraceRecorder` records task scheduled/yielded/completed/spawned, time advanced, timer created/fired/cancelled, io ready/result/error, rng seed+values, chaos injections, waker wakes (`src/trace/recorder.rs:466-660`).
- **Home.** Skill interface self-tests (known-answer under fixed seed); reproducibility gate (the list of nondeterminism sources to pin).
- **Cost.** Discipline more than code; the seeded-hasher requirement is easy to miss (they hit it: `:2112-2116` comment).
- **Evidence.** PROVEN-in-source (same tests as M1; `tests/lab_determinism.rs` has 20+ same-seed tests, names at `:149-1181`).
- **Gotcha.** `TraceReplayer` (`src/trace/replayer.rs`) is a diff/validator; nothing in `src/lab` drives a runtime from a `ReplayTrace`. Exact replay is M1.
- **Risk.** None.

### M3. Obligation linear-token state machine + completion audit
- **Mechanism.** `ObligationState{Reserved,Committed,Aborted,Leaked}`; resolve-once (`commit/abort/mark_leaked` panic on double resolve) (`src/record/obligation.rs:192-222,440-470`). On non-cancelled task completion the runtime audits obligations still held and routes them to `handle_obligation_leaks`, which marks `Leaked`, counts, escalates by threshold, and either fails fast or logs (`src/runtime/state.rs:6688-6714,4640-4720`). Channel permits abort their reservation on `Drop` (`src/channel/mpsc.rs:1290-1308`). Lean: `leak_marks_leaked`, `leak_removes_from_ledger` (`Asupersync.lean:706,769`).
- **Home.** Dead-end ledger / branch tree invariant: every opened hypothesis or claim must reach a terminal status (REFUTED/PARKED/PROVEN/…) — "leaked" = worker exited without resolving; fail-fast in tests, log+escalate in production.
- **Cost.** A small enum + an audit hook at worker exit.
- **Evidence.** STRONG-EMPIRICAL (implementation read end-to-end; tests exist — `panic_on_leak(true)` in `deterministic_validation_tests.rs:33-41`, `test_lab_io_quiescence_waits_for_obligation` `tests/lab_determinism.rs:1095` — bodies not read).
- **Risk.** None.

### M4. E-process (anytime-valid) monitors
- **Mechanism.** (a) Binary betting martingale `E_t = E_{t-1}(1+λ(X_t−p0))`, λ validated in `(−1/(1−p0), 1/p0)`, capped at `max_evalue`, reject at `1/α` (`src/lab/oracle/eprocess.rs:84-130,224-255`); wired into `OracleSuite::new()` by default (`src/lab/oracle/mod.rs:336-346`). (b) `LeakMonitor`: LR = max(1, x/μ)/(1+1/e), whose expectation under Exp(μ) is exactly 1 (arithmetic at `src/obligation/eprocess.rs:172-203` checks out).
- **Home.** Calibration layer — the strong-law-of-small-numbers gate. An orchestrator that peeks after every experiment needs a stopping rule valid under optional stopping; e-processes give that (Ville).
- **Cost.** ~100 lines; must state H0 and independence explicitly.
- **Evidence.** STRONG-EMPIRICAL. (a) is the textbook formula with range validation; tests named `eprocess_martingale_conformance`/`statistical_convergence_properties` (`src/obligation/eprocess.rs:710,879`). (b)'s `supermartingale_property_under_null` test is a deterministic slack check (`e <= 2.0`, `:595-625`), not a statistical one. (b)'s validity assumes fresh independent draws; repeatedly observing the *same* stuck item's growing age breaks it (production use feeds per-message latencies, `src/messaging/service.rs:1841`).
- **Risk.** None if used only to *withhold* promotion; it must never substitute for a proof.

### M5. Split-conformal quantile with honest +inf
- **Mechanism.** Threshold = `ceil((1−α)(n+1))`-th order statistic; returns `+inf` when rank > n instead of clamping (which would silently lose the finite-sample guarantee) (`src/lab/conformal.rs:542-560`; design `:1-37`).
- **Home.** Small-scale ladder — distribution-free interval for the next bit-size's runtime/yield from exchangeable toy runs; STRONG-EMPIRICAL calibration.
- **Cost.** ~20 lines. **Evidence.** STRONG-EMPIRICAL (tests `sparse_calibration_uses_infinite_threshold_for_high_coverage` `:1066`, `coverage_tracking` `:1104`, names). **Risk.** None; exchangeability must be stated.

### M6. Budget semiring + budget-aware restart refusal
- **Mechanism.** Meet = min deadline/poll/cost, max priority (`src/types/budget.rs:496-545`); exhaustion at checkpoint yields a `CancelReason` chosen by `strengthen` (max severity, earlier timestamp tie-break) (`src/cx/cx.rs:2603-2648`; `src/types/cancel.rs` strengthen body). Supervision refuses a restart when `restart_cost`, `min_remaining_for_restart`, or `min_polls_for_restart` cannot be afforded (`src/supervision.rs:214-300`; policies OneForOne/OneForAll/RestForOne + EscalationPolicy `:380-425`).
- **Home.** Tier scheduler / cost profiles: child budget = meet(parent, declared profile); "retry only if affordable".
- **Cost.** Small. **Evidence.** STRONG-EMPIRICAL (bodies read; tests `region_table.rs:1228-1232` proptest names). **Risk.** None.

### M7. Spec-first posture contract
- **Mechanism.** A test (`tests/formal_proof_posture_contract.rs:7-14`) reads the posture JSON, `formal/README.md`, the invariant inventory and the Lean file and asserts they agree, so README cannot claim more than the inventory; TLC output is a JSON receipt (`formal/tla/output/result.json`).
- **Home.** Formalization gate ("statement-level review" as a machine-checked contract between claim text and Lean statement).
- **Cost.** A JSON schema + one test. **Evidence.** STRONG-EMPIRICAL as a pattern. **Risk.** Positive, with the caveat that model-level theorems are not runtime proofs.

### M8. Bounded, versioned, SHA-256-attested proof artifacts (RaptorQ `DecodeProof`)
- Caps (`MAX_PIVOT_EVENTS=256`, `MAX_RECEIVED_SYMBOLS=1024`), schema version, 32-byte attestation hash (`src/raptorq/proof.rs:1-80`). Home: substrate succinct certificates — pattern only. Evidence CONJECTURE for Cairn (verify path not read). Risk none.

### Not accretive / absent
- **RaptorQ itself**: real and differential-tested, but candidate_home NONE (no erasure-coded transfer lane in Cairn) — homeless cleverness.
- **Hash-chained append-only log**: absent from the library; a `hash_chain`/`previous_hash` structure exists only inside a test (`src/real_obligation_saga_trace_integrity_integration_e2e_tests.rs:88-384`). `franken_evidence` is an unchained JSONL decision-ledger schema (`franken_evidence/src/lib.rs:1-45`). Trace files carry SHA-256 of metadata and event stream (`src/trace/file.rs:27-33,178-179`) — integrity, not chaining. `TraceCertificate` hashes with a fixed-seed 64-bit `DetHasher` (`src/trace/certificate.rs:66-87`; `src/util/det_hash.rs:59-69`) — determinism check, not attestation.

**Verdict.** Borrow M1 (exact-dispatch receipt with typed mismatch errors and a sealed, config-bound artifact) for the reproducibility gate, and M4(a)/M5 for the calibration layer. Do not adopt the crate.
