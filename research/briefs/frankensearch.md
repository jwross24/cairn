## frankensearch v1.6.0 (@ 4302c377169c)

**What it actually is.** A 14-crate Rust workspace (~770K lines, nightly-2026-07-20 pinned) implementing two-tier hybrid local search: Quill (own BM25, k1=1.2/b=0.75 pinned to Tantivy 0.26.1) + Model2Vec static embeddings (potion-multilingual-128M, 256-d) + optional ONNX MiniLM (384-d) + pure-Rust int8 cross-encoder (ms-marco-MiniLM-L-6-v2 via git-pinned frankentorch), fused with RRF, served progressively (Initial → Refined). It is mature and heavily unit-tested (tens of `#[test]` per module; property/MC tests in the statistical modules), but large parts (quill-gauntlet 161K lines, ops/TUI) are campaign/evidence tooling rather than search. The watchlist hypothesis "no conformal/calibration" is **refuted**: there are real conformal, calibration, e-process and recall-certificate modules.

### 1. Certified recall lower bound + cheapest-config sweep
- **Mechanism.** Split-conformal per-query lower tolerance bound `L = ⌊α(n+1)⌋-th smallest calibration recall` (returns trivial 0.0 when n too small instead of inventing a number); Hoeffding and empirical-Bernstein (Maurer–Pontil) mean bounds; `calibrate_certified_ef`: try candidate configs cheapest-first, measure recall lazily, stop at the first whose *certified* bound meets target; else return best-certifiable with `meets_target=false`, with the whole sweep retained as audit trail.
- **Home.** Tier gate / tier scheduler (admission of a cheaper tier-N config by certified evidence from tier N−1) and small-scale ladder ("measured scaling" with a finite-sample bound). Also the CONJECTURE→STRONG-EMPIRICAL boundary in the calibration layer.
- **Cost.** ~300 lines, zero deps; needs an exchangeable calibration sample and an exact oracle to measure against (the ladder supplies both).
- **Evidence.** PROVEN-in-source: impl `index/src/recall_certificate.rs:28-312`; MC coverage test `:353-384`, mean-bound coverage `:397-420`, Bernstein tighter-than-Hoeffding `:449`, overconfident-heuristic refusal `:595-611`; wired into `HnswIndex::certify_ef_search` `index/src/hnsw.rs:1329-1375`.
- **Epistemics risk.** None; it replaces a magic heuristic with a guarantee and fails to 0.0 rather than optimistic.

### 2. Conformal rank calibration: required_k, p-value, Mondrian per-class, adaptive α
- **Mechanism.** Calibration = sorted relevant-document ranks; `required_k(α)` = conformal quantile index ⌈(n+1)(1−α)⌉ (`conformal.rs:453-470`); `p_value = (#{rank ≥ obs}+1)/(n+1)` (`:208-228`); Mondrian: per-query-class model when ≥ min examples, else global fallback (`:240-298`); ACI update `α_t = clamp(α + γ(err − α))` (`:358-430`). Deserialization validates sortedness/1-indexing (`:33-70`). Used in searcher only to raise the candidate budget (`fusion/src/searcher.rs:2878-2894`).
- **Home.** Workers: Librarian (how deep to retrieve for coverage 1−α that prior art, if it exists, is in the set) and problem queue novelty scoring; dead-end ledger advisory retrieval.
- **Cost.** ~450 lines, zero deps; needs labeled (query, rank-of-relevant) calibration pairs.
- **Evidence.** PROVEN-in-source for the mechanics: held-out coverage test `conformal.rs:576-591`; 40 tests. The guarantee is per-exchangeable-query; Cairn's queries are not i.i.d. with any calibration set, so treat output as a budget, not a certificate.
- **Epistemics risk.** Low if advisory; a conformal p-value must never be read as "novel/proven".

### 3. PhaseGate "e-process" — DO NOT BORROW AS-IS
- **Mechanism.** Multiplicative evidence `e_t = Π f(Δ_t)` with `f = 1+min(Δ,1)` if quality better, `1/(1+min(|Δ|,1))` if fast better, ties 1.0, user-signal ×1.5/×0.7; decide when `e ≥ 1/α` or `1/e ≥ 1/α`; timeout forces a decision; reset on expiry; emits `EvidenceRecord`s (`phase_gate.rs:152-270, 311-340`).
- **Finding.** Under the stated H0 ("scores exchangeable", `:304-310`) this `f` is not an e-variable: E[f] > 1 (Jensen), so Ville's inequality does not apply. Reproduction (scratchpad/sim/phase_gate_null.py, default config): E[f]=1.013 at Δ~U(−0.3,0.3), 1.097 at U(−1,1); threshold-crossing rate under null before timeout = 36%/37% and 51%/49% per side vs claimed 5%. None of the 32 tests (`:459-983`) checks null validity.
- **Home.** Tier gate / strong-law-of-small-numbers gate — only the *protocol shape* (accumulate, stop at 1/α, ledger on decision, reset on regime change) with a real e-value (e.g. betting-martingale on bounded outcomes, or mechanism 1).
- **Cost/Evidence.** CONJECTURE as a valid test; real code, reachable (`searcher.rs:609-617, 1132-1137`).
- **Epistemics risk.** High if copied: a gate that fires ~40% under null while labeling itself 95%-confident would let strategy leak into truth.

### 4. Embedding identity bundle + golden-vector certificate (typed skill identity + known-answer self-test)
- **Mechanism.** `EmbeddingIdentityBundleV1 = {space, producer, input, storage}`; space = logical model id + immutable revision + role-tagged artifacts each with SHA-256+size + tokenizer/vocab fingerprints (`core/src/generation.rs:1780-1860`); producer = backend, implementation_revision, protocol_revision, numeric_profile, provenance-manifest fingerprint, golden certificate (`:2363-2412`); certificate = SHA-256 over a domain-separated canonical transcript of an ordered fixed corpus and the exact `f32::to_bits` outputs (`:2220-2300`, corpus `embed/src/model_manifest.rs:61-70`); compatibility: exact producer match or `CertificateRequired`; mismatch → `GoldenVectorMismatch` (`generation.rs:2560-2580`).
- **Home.** Skill interface + self-tests (typed identity, fixed version, known-answer self-test) and the substrate hash key (skill@version, inputs-by-hash, tool-versions).
- **Cost.** Schema discipline + canonical encoder; moderate. Bit-exact outputs need a pinned numeric profile; floating skills in Cairn need a tolerance policy or that pin.
- **Evidence.** STRONG-EMPIRICAL: impl read; test `model_manifest.rs:3351-3400` shows a changed backend with identical space ⇒ `CertificateRequired`; fail-closed by construction. I did not trace every validate path.
- **Epistemics risk.** None; strengthens reproducibility gate.

### 5. Gauntlet evidence protocol: content-addressed artifacts, retained-but-inadmissible generations, named evidence slots, ratchet with null controls
- **Mechanism.** Artifact objects hashed under domain-separated SHA-256 per schema generation (`quill-gauntlet/src/artifact.rs:58-90`); older generations stay addressable and re-derivable but "not admissible evidence and nothing mints them" (`:46-56`); append-only Divergence Register ledger (`runner.rs:65, 1272-1300`); `ReplacementAuthorizationV1` requires five named slots, each proven load-bearing by a test removing exactly that one, refusal names the slot, "a passing conformance suite means correct, never authorized" (`replacement_authorization.rs:1-42, 60-85`; tests `:941-1568`); perf ratchet: quarantine noisy results, same-revision rerun before promotion, A/A null control band, max 5% regression (`perf_ratchet.rs:1-60`); ledger convention separating SELF-SPEEDUP from INCUMBENT claims (`docs/PERF_LEDGER.md:3-25`).
- **Home.** Substrate (lineage forever, superseded schema = recognized-but-inadmissible), gate layer (reproducibility/formalization gate as independently load-bearing slots), negative-results map (entry schema in `docs/NEGATIVE_EVIDENCE.md:3-15`: hypothesis, immutable receipt SHA, method, result+CI, decision, retry predicate).
- **Cost.** Copy the protocol, never the crate (161K lines, unpublishable, dev-only).
- **Evidence.** STRONG-EMPIRICAL: heads + test names read (artifact 61, ratchet 78, runner 99, authorization 16 tests); bodies not read.
- **Epistemics risk.** None; exactly the "green ≠ authorized" posture Cairn wants.

### 6. Paired bootstrap + run-stability verdict + IR metrics
- **Mechanism.** `bootstrap_compare`: paired diffs, seeded xorshift resampling, percentile CI, shift-method two-sided p with +1 correction (`core/src/metrics_eval.rs:401-470`); `bootstrap_ci` (`:338-395`); `verify_run_stability`: IQR-trim then CV ≤ max and n ≥ min, reason string on failure (`:624-700`); nDCG/MAP/MRR/Recall with dedup of repeated ids (`:25-135`).
- **Home.** Small-scale ladder (a scaling claim needs a stability verdict + paired CI) and skill self-tests; supports the STRONG-EMPIRICAL tag definition.
- **Cost.** ~400 lines, zero deps. **Evidence.** STRONG-EMPIRICAL (bodies read; 79 tests not read). **Epistemics risk.** None.

### 7. SimHash document fingerprint (near-duplicate, advisory)
- **Mechanism.** 64-bit SimHash over 3-token shingles (FNV-1a), plus exact FNV content hash, char/token counts; decision: same content hash → no; char-count delta > 20% → yes; else Hamming/64 > 0.125 (`core/src/fingerprint.rs:25-110, 252-330`).
- **Home.** Dead-end ledger near-duplicate detection as an ADVISORY "resembles REFUTED branch X" signal; problem-queue novelty.
- **Cost.** ~150 lines, zero deps. **Evidence.** PROVEN-in-source (23 tests `:365-630`, e.g. formatting-invariance `:417`). **Epistemics risk.** Must remain advisory: near-dup ≠ same hypothesis; REFUTED is by exact hash only.

### 8. RRF with explicit deterministic 4-level tiebreak, f64 accumulation
- **Mechanism.** `1/(k+rank+1)` per source, first-occurrence wins, weights sanitized, sort by score↓, in_both, lexical↓, doc_id↑ (`fusion/src/rrf.rs:112-130, 190-330`). Measured guidance: hybrid ≥ best single tier on 3 BEIR sets, never ensemble two embedders, k≈10, RRF ≈ score fusion but scale-free (`docs/SEARCH_QUALITY_FINDINGS.md:28-75`).
- **Home.** Librarian lit-grounding retrieval. **Cost.** Small; or depend on `frankensearch-fusion` with `hybrid`. **Evidence.** PROVEN-in-source for determinism/formula (57 tests, `:1528-1734`); STRONG-EMPIRICAL for quality guidance (doc, not re-run). **Epistemics risk.** None.

### 9. OPE (IPS/DR) and Bayesian adaptive fusion
- **Mechanism.** Clipped IPS with ESS reliability flag, DR (`fusion/src/ope.rs:1-100`); Beta(7,3)/Normal(60,10²) posteriors with clamps and min-samples before use (`adaptive.rs:1-110`).
- **Home.** Orchestrator: evaluate a proposed allocation policy offline from logged branch outcomes + propensities before switching. **Evidence.** CONJECTURE (heads only; 32/40 tests unread). **Cost.** Small; needs logged propensities. **Epistemics risk.** None (strategy-side only).

### Not accretive for Cairn
Score calibration (Platt/temperature/isotonic PAVA + ECE/Brier, `calibration.rs:1-420`, 60 tests) is sound but calibrates retrieval probabilities, which no Cairn component consumes. Exact-content dedup (`storage/src/content_hash.rs:14-50, 140-250`) is SHA-256 of canonical text scoped by embedder id — Cairn's substrate already subsumes it. Circuit breaker, MMR, PRF, hubness, federated: search-product concerns.

**Verdict.** Most accretive: the recall-certificate pattern (conformal/Bernstein lower bound + cheapest-config sweep that refuses to certify when n is small) as the template for tier-gate admission and ladder claims; second, the golden-vector known-answer certificate as the skill self-test shape; third, the gauntlet's named-slot authorization + retained-inadmissible generations. Negative lesson: PhaseGate's e-process is not valid — Cairn's small-numbers gate must use a real e-value.
