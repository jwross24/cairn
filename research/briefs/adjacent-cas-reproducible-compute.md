## Content-addressed stores & reproducible-compute substrates

Target: SUBSTRATE (PLAN §3) and REPRODUCIBILITY GATE. Everything below was read this session from the cited proto/spec/source; commits are in `scratchpad/adjacent/*`.

### Answers to the four questions

**(1) Canonical action serialization.** REAPI keys the action cache by the digest of the binary protobuf wire encoding of `Action{command_digest, input_root_digest, timeout, do_not_cache, salt, platform}`. Canonicalization is normative: fields serialized in tag order, no unknown or duplicate fields, default semantics (`remote_execution.proto` L1097-1107 @ becdd8f); `Command.environment_variables` MUST be sorted by name, output paths deduplicated and sorted by code point (L716-795); `Directory` children sorted by path by code point (L925-933). `Digest` = (lowercase hex hash, size_bytes) and size is integral to the key (L1078-1082). `DigestFunction` enumerates SHA256, SHA256TREE, BLAKE3=9 (L2125-2200). The server MAY skip enforcing canonical form, in which case two logically equal actions that hash differently are simply distinct (L55-62). Nix: store path = nix32(truncate160(sha256(`type:sha256:inner:store:name`))), inner digest for input-addressed outputs = SHA-256 of the ATerm derivation after `hashQuotientDerivation` substitutes input derivations by their own hashes (quotient = equivalence class of derivations). Unison: SHA3-512 of the syntax tree with names erased and dependencies replaced by hashes; mutually recursive cycles canonicalized by sorting members. IPLD DAG-CBOR: a strict subset of RFC 8949 §4.2 (shortest ints, definite lengths, map keys sorted length-first then bytewise, only tag 42, float64 only, single object) (`ipld-specs/block-layer/codecs/dag-cbor.md` L55-76 @ a7b9376).

**(2) Nondeterministic outputs.** REAPI: `Action.do_not_cache` means "result cannot be cached and in-flight requests may not be merged" (L651-653); `ExecuteResponse.status != OK` → result MUST NOT be cached (L1605-1615); `ExecuteRequest.skip_cache_lookup` forces re-execution and the new result SHOULD overwrite a poisoned entry (L1527-1539); `Action.salt` moves an entire class of results into a fresh namespace to disown poisoned caches (L657-663). REAPI has no determinism check — "Ideally, all Actions will be reproducible" is a hope, not a mechanism (L604-607). Nix has the mechanism: a fixed-output derivation declares the output's content address in advance and the build fails if the produced content does not match; "all parts of the output must be cryptographically fixed with one or more hashes"; input-addressed derivations must be pure, impure ones must be fixed-output. `nix-build --check` rebuilds an existing output and exits 1 ("may not be deterministic") on a bitwise mismatch, keeps the second result at `<path>.check`, and runs `diff-hook` only when results differ. The manual's design note sketches a "stand-alone assertion object" for a content address separate from the derivation (issue #11955) — that is exactly Cairn's certificate. Hermit defines "replayable" mechanically: threads sequentialized under a deterministic scheduler with PMU retired-branch preemption, virtual time from progress, seeded RNG (`--rng-seed`, `--sched-seed`), CPUID table; record/replay covers only irreducibly external inputs (fs, mmap, network, random, time) — "anything Detcore can emulate or order locally is not recorded". FoundationDB: single-threaded discrete-event simulation, all nondeterminism sources (network, disk, time, PRNG) abstracted behind a seed; any real thread breaks it.

**(3) Retention.** Nix: liveness = closure reachable from GC roots (symlinks under `/nix/var/nix/gcroots`, indirect roots via `auto/`); `keep-derivations=true` (default) keeps the `.drv` of live outputs "for querying and traceability"; `keep-outputs=false` default; the build trace is a separate memo table `(drv, output) → content hash`; `.check` paths are not GC-protected. REAPI: AC lifetime is implementation-specific; `GetActionResult` SHOULD ensure referenced blobs are present "and will be for some period afterwards" and SHOULD extend their lifetimes (L153-160). Buildbarn `CompletenessCheckingBlobAccess` returns NOT_FOUND for an ActionResult if any referenced CAS blob is missing, and `FindMissing` must be "exactly right" and touch present objects (bb-adrs/0002-storage.md); bazel-remote does the same in `GetValidatedActionResult` (`cache/disk/disk.go` L812-930 @ ead2079), with size-bounded LRU sorted by atime on load (`load.go` L580-581). Buildbarn `ActionResultExpiringBlobAccess` hides results older than `minimum_validity` (+deterministic jitter) and `minimum_timestamp` invalidates a poisoned AC.

**(4) Embeddable CAS.** bazel-remote: single Go binary, SHA256 keys only (README L27; `HashKeyRegex ^[a-f0-9]{64}$` at `utils/validate/action_result.go` L34), LRU by `--max_size`, zstd storage, AC validation — no roots, no lineage, LRU evicts what Cairn wants forever. NativeLink: Rust single binary, configurable stores, `EvictionPolicy` LRU by max_bytes/max_seconds/max_count, sha256 or blake3 digest function — a scheduler/worker system, not a library. cacache-rs (@105692a): Rust library, `content-v2/<algo>/xx/yy/<hex>` layout, index buckets by sha256(key), algorithms via ssri = Sha512/Sha384/Sha256/Sha1/Xxh3 (no BLAKE3), atomic writes and verify-on-read, no eviction policy or roots. None provide lineage or roots; those are tables regardless. Verdict: SQLite (blobs + lineage + roots) keyed by BLAKE3 at M0, borrowing semantics, not binaries.

### Per-source

**REAPI Action/Digest canonicalization** → SUBSTRATE artifact-key schema. Mechanism: key = digest of a canonical binary encoding of {recipe digest, input-root Merkle digest, timeout, flags, salt, platform}; (hash,size) pair. Cost: write a canonical encoder (sorted maps, tag order) and test it with a known-answer vector; ~200 lines. Evidence: PROVEN-in-source (proto L55-62, L1097-1107, L716-795). Risk: none to epistemics; the opposite — "logically equal ⇒ same key" is only as true as your canonicalizer; REAPI explicitly lets non-canonical inputs split into distinct keys, so Cairn's REFUTED-by-collision needs the canonicalizer to be the enforced one.

**REAPI do_not_cache / skip_cache_lookup / status≠OK / salt** → REPRODUCIBILITY GATE + Skeptic. Mechanism: three explicit bits separating "never cache", "re-run even if cached, overwrite", "failed ⇒ uncacheable", plus a namespace salt to disown poisoned results. Cost: three columns and one policy. Evidence: PROVEN-in-source (L651-663, L1527-1539, L1605-1615). Risk: a cache hit must never stand in for a gate pass; the Skeptic's independent re-run is `skip_cache_lookup=true` by construction.

**Nix fixed-output derivation + stand-alone assertion note** → SUBSTRATE certificate type for non-replayable work. Mechanism: certificate = declared content address; any consumer can verify "this artifact has this hash" without re-deriving; build fails on mismatch; impure ⇒ must be fixed. Cost: a certificate schema {method, algo, hash, producer, evidence-tag}; near zero. Evidence: PROVEN-in-source (manual store/derivation/outputs/content-address, protocols/store-path). Risk: a hash assertion certifies identity, not truth; certificate-backed artifacts must keep the producer's calibration tag and never be promoted by the gate.

**Nix `--check` + diff-hook + `.check` path** → REPRODUCIBILITY GATE definition. Mechanism: rebuild from the same recipe, compare bitwise, keep the divergent copy, exit nonzero, run a diff hook only on mismatch. Cost: one extra run per checked artifact. Evidence: PROVEN-in-source (advanced-topics/diff-hook). Risk: none; this is the gate. Note `.check` paths are not GC-protected in Nix — Cairn should root them (they are the evidence of non-reproducibility).

**Nix GC roots + keep-derivations + build trace** → SUBSTRATE GC. Mechanism: roots are explicit; liveness is closure; recipes (`.drv`) of live outputs survive by default while outputs can die; build trace is a separate table. Cost: a roots table and a mark phase over lineage edges. Evidence: PROVEN-in-source (nix.conf keep-derivations/keep-outputs, nix-store --gc, Determinate "Build Trace"). Risk: Nix drops the `.drv` of *dead* outputs; Cairn's "lineage forever" is stricter — model it as "recipes and ledger rows are always roots; only blobs are collectable."

**Buildbarn CompletenessChecking / bazel-remote GetValidatedActionResult** → SUBSTRATE read path. Mechanism: a cached result is served only if every referenced blob exists; otherwise NOT_FOUND and recompute. Cost: one FindMissing per hit. Evidence: PROVEN-in-source (disk.go L812-930; bb-adrs 0002). Risk: none; prevents a REFUTED/PROVEN row whose evidence blob was GC'd from being treated as replayable.

**in-toto Statement v1 + ResourceDescriptor + DSSE** → SUBSTRATE certificate envelope / claims DB. Mechanism: `{_type, subject:[{name,digest:{algo:hex}}], predicateType, predicate}`; subjects matched purely by digest; DSSE signs raw payload bytes ("SHOULD avoid depending on canonicalization"); `test-result` and `link` (materials/products) predicates exist. Cost: JSON, one dependency (or none; it is a shape). Evidence: PROVEN-in-source that the format and parsing rules exist (`spec/v1/statement.md`, `resource_descriptor.md`, `envelope.md` @ 051624c); benefit to Cairn CONJECTURE. Risk: low; recommend adopting the Statement shape and DSSE store-the-bytes rule, not in-toto tooling; BLAKE3 is absent from the DigestSet list (blake2b is) so register it per the "new algorithms MUST document encoding" rule.

**Hermit / FoundationDB** → REPRODUCIBILITY GATE vocabulary only. Mechanism: replayable iff every nondeterminism source is seeded, virtualized, or recorded. Cost of Hermit as a tool: Linux x86-64 ptrace, 3-6x wall clock, nightly Rust — reject as M0 dependency. Evidence: STRONG-EMPIRICAL (README, ARCHITECTURE.md in the rrnewton fork). Risk: "replayable" is relative to (tool build, binary, config, seed); Cairn's key already pins these.

**Unison content-hashed definitions** → LEMMA LIBRARY identity. Mechanism: hash of the term with names erased and deps by hash; names are metadata; results cached by hash. Evidence: PROVEN-in-source (language-reference/hashes). Application to Lean declarations is CONJECTURE and needs a canonical elaborated form — park.

**Dagster data versions** → STATE LAYER staleness flag. Mechanism: data_version = hash(code_version, input data_versions); default code_version = run ID, so without explicit versions nothing ever dedups. Evidence: STRONG-EMPIRICAL (docs). Marginal over what Cairn already hashes; the lesson is "skill@version must be explicit or collision-by-hash is silently dead."

### Rejected
- Buildbarn `ActionResultExpiring` time-based expiry → would age out ledger rows; cache-only concept, contradicts immutable epistemics.
- bazel-remote / NativeLink / cacache-rs as M0 dependency → LRU-only retention, no roots/lineage, SHA256 or no BLAKE3 (cacache), or a whole execution system (NativeLink).
- Hermit as a runtime → cost/platform; keep the definition.
- IPLD CIDs as identifiers → multibase/multicodec/multihash self-description is useful only across systems; DAG-CBOR strictness rules are worth copying if Cairn picks CBOR over protobuf canonical rules.
- IPFS pinning, DVC/Pachyderm, Perkeep/OSTree, Antithesis → not read this session; no claim.
