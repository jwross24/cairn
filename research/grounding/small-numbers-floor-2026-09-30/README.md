# Small-numbers floor study

The floor records an exact rational e-process for the immutable hunt distribution.
Its records are resource observations outside `evidence_nodes`; they cannot justify
a claim tag, reward, or mathematical proof. The experiment uses the real hunt runner,
process receipts, and fresh uncached recipe reruns.

`preregistration.json` fixes the control statements, distributions, failure coding,
stakes, budgets, and adoption rule. The driver requires a full committed source SHA
whose entire `src/cairn` runtime tree, dependency manifest and lockfile, fixture workers,
driver, and preregistration match disk exactly. Untracked runtime sources and resources
are refused; generated `__pycache__` bytecode is excluded from the source inventory.
Each case has one fresh gate-owned nonce. A rerun reproduces that nonce's points and substantive transcript;
it supplies no independent statistical sample.

```bash
uv run python research/grounding/small-numbers-floor-2026-09-30/run_experiment.py \
  --source-sha <full-committed-sha> --output <new-artifact-directory>
```

The output holds `substrate.sqlite` and `summary.json`. The database retains recipes,
dispatch settings, input/output blobs, receipts, protocol/run registrations, floor
results, and real reproducibility records. The summary retains every declared seed,
exact final wealth as `hex:numerator/denominator`, numeric display attributes,
completed counts, errors, hashes, tag invariance, and the decision. Scratch process
directories reside in a separate temporary directory named in the summary.
Completed comparisons retain a content-addressed decision node with the registered
criterion, epsilon/alpha/distribution bindings, result and reproduction lineage,
and `enforced=false`. Incomplete comparisons cannot mint that node.
Interpreter identity and installed runtime package versions accompany the source SHA;
package version metadata does not assert byte identity of third-party installations.

An incomplete execution leaves the decision `INCOMPLETE`; it is neither a clean
survivor nor a completed adoption/drop comparison. An `ADOPT` decision records a
resource floor without enforcing it. Tier-2 proving admission requires a separate
reviewed gate and bundle-pinned policy. The comparison
concerns only the registered synthetic distributions and schedules. The derived
redundancy at budgets `3/epsilon` is arithmetic, not sampled evidence or a Lean proof.
